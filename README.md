# MaisCordenador
Canal para comonicação entre aluno e coordenador


Frameworks
- Fastapi
- Bootstrap


Como contribuir ao projeto:

De **git clone** no projeto e na pasta de projeto faça o seguinte, no diretório do projeto

```bash
uv sync
```

#### Importante 
Use o [Uv](https://docs.astral.sh/uv/)
